# Редакционный стандарт журнала путешествий

Путешествие публикуется как последовательность законченных визуальных историй, а не как общий фотоальбом и не обязательно как календарный дневник. Главой может быть день, часть дня, место, маршрут, событие, тема, несколько связанных дней или всё короткое путешествие. Для каждой главы редактор сначала рассматривает изображения без опоры на имя файла, EXIF-время или ожидаемый маршрут, затем определяет реальные сцены и только после этого восстанавливает фактическую последовательность.

## Обычный отбор главы

1. Одно главное изображение.
2. Обычно от шести до восьми изображений основной истории: начало, развитие, ключевой момент, финал. Короткая глава может быть меньше, большой самостоятельный сюжет — больше.
3. Отдельная компактная серия «За кадром».
4. Повторы, технически слабые и не относящиеся к путешествию кадры исключаются.

Текст допустим только из фотографий, заметок автора, подтверждённого маршрута и проверенных фактов. Имя файла и дата съёмки не являются доказательством содержания кадра.

## Статусы

- `awaiting_visual_review` — фотографии ещё не просмотрены как изображения; публичная фотоглава не строится.
- `draft_review` — предварительная журнальная последовательность готова для автора.
- `approved` — автор прямо утвердил версию; только этот статус разрешает публикацию.

Генератор не должен автоматически превращать весь загруженный набор в галерею и не должен выбирать первые файлы как обложку.
