# Как создать новое путешествие

## Самый простой способ: с телефона

1. Откройте на сайте `/author.html` — страницу можно установить на главный экран как приложение.
2. Заполните название, период и описание поездки.
3. Добавьте любое количество глав. Для каждой главы укажите темы и места обычными словами через запятую.
4. Для каждой главы создайте отдельный альбом Google Фото с нужными кадрами и вставьте общедоступную ссылку. Либо выберите фотографии из медиатеки телефона.
5. Нажмите **«Скачать заявку на путешествие»** и отправьте полученный JSON-файл редактору.

Черновик автоматически хранится на телефоне, поэтому форму можно закрывать и продолжать позже. Программировать и редактировать JSON не требуется. Ссылки на альбомы попадут в заявку рядом с соответствующими главами. Оригиналы фотографий не помещаются внутрь JSON.

### Как подготовить Google Фото

1. Создайте **отдельный альбом для каждой главы**, например «Грузия — Тбилиси».
2. Добавьте туда только те фотографии, которые можно использовать для этой главы.
3. В Google Фото нажмите «Поделиться» → «Создать ссылку».
4. Вставьте ссылку в поле главы и проверьте её в приватной вкладке браузера: альбом должен открываться без входа в ваш аккаунт.

Не вставляйте ссылку на всю медиатеку. Общая ссылка на альбом сообщает редактору точный набор кадров, но не даёт сайту постоянный программный доступ к вашему аккаунту Google.

Редактор или автоматизация применяет заявку одной командой:

```bash
npm run trip:new -- --request ~/Downloads/georgia-2027-new-trip.json
```

## Резервный способ: команда

Из корня проекта выполните:

```bash
npm run trip:new -- \
  --id georgia-2027 \
  --title "Грузия 2027" \
  --subtitle "Тбилиси, Сванетия и море" \
  --period "Май 2027" \
  --description "Путешествие по городам и горам Грузии" \
  --cover "https://example.com/cover.jpg"
```

`--id` — постоянный технический идентификатор. Используйте только строчные латинские буквы, цифры и дефисы; после публикации его лучше не менять. `--cover` необязателен и может указывать на любой доступный по HTTPS файл — Cloudinary не требуется.

Команда автоматически:

- добавит карточку в `data/trips.json`, поэтому поездка появится на главной;
- создаст публичную страницу `trips/georgia-2027/index.html`;
- создаст `data/georgia-2027/trip.json` с тремя начальными представлениями: «Главы», «По темам» и «По местам».

## 2. Добавить материалы

Откройте `data/georgia-2027/trip.json` и добавляйте элементы в нужные `views[].items`. Путешествие не обязано состоять из дней: главой может быть место, тема, человек или отдельная история.

```json
{
  "id": "tbilisi",
  "title": "Тбилиси",
  "description": "Дворы, серные бани и вечерний город.",
  "href": "chapter-tbilisi.html"
}
```

Один материал можно добавить ссылкой в несколько представлений, например одновременно в «Главы», «Города» и «Архитектура».

## 3. Отобрать фотографии на телефоне

1. Откройте на сайте `/photo-import.html`.
2. Нажмите **«Выбрать фотографии»** и выберите снимки из медиатеки или приложения «Файлы».
3. Дождитесь локальной проверки резкости, экспозиции и дублей.
4. Просмотрите предварительный выбор и скачайте JSON.

Страница не является облачным хранилищем: оригиналы никуда не отправляются. После отбора выбранные файлы нужно положить в доступное хранилище или каталог сайта, а их URL добавить в материалы. Для мобильной загрузки без Cloudinary практичный следующий этап — подключить хранилище с системным выбором файлов (например, репозиторий через форму загрузки или S3-совместимое хранилище); текущая версия намеренно выполняет только безопасный локальный отбор.

## 4. Проверить и опубликовать

```bash
npm test
python3 -m http.server 8000
```

Откройте `http://localhost:8000/trips/georgia-2027/`, проверьте все представления, затем закоммитьте изменения. Пока `status` равен `active`, поездка видна на главной; значение `hidden` скрывает её.
